Permutaciones
Una permutación constituye un ordenamiento de un conjunto de elementos.
Ejemplo
¿Cuántas permutaciones hay de las letras A, B y C? Escribir todas las maneras
diferentes posibles.
Con solamente tres elementos, es fácil determinar el número de permutaciones,
sólo con hacer una lista de todas ellas. Pero con un gran número de elementos
esto último no sería factible. El principio fundamental de conteo se puede usar
para determinar el número de permutaciones de cualquier conjunto de elementos.
